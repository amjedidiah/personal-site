Kairo is an interactive website built around a fictional world. Its sections invite visitors to explore the Echo Tree, consult an AI-guided oracle, and follow a comic-style story.

## Hardest challenge

The story-led interface also has live community state, authentication, and an oracle. Those features need to feel like parts of one world while their API and database work remains dependable beneath the visual experience.

## What I worked on

- Responsive React interface and animated transitions
- Interactive story and exploration pages
- Integration of the site's visual language across the experience
- API routes and persistent data for community features

## Lessons learned

Separating the visual story from persistent community state keeps animation and backend behavior easier to change independently. Motion works best here when it helps visitors understand where they are and what just happened.
