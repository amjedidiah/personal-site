Multiplayer AI agent platform. Real-time collaborative sessions where multiple users interact with AI agents simultaneously.

## What it does

Gwela lets teams run shared AI sessions with WebSocket streaming, multi-provider LLM support (OpenRouter, Ollama), and full run management. Think Google Docs but for AI agent interactions.

## Technical highlights

- Python FastAPI agent service with WebSocket streaming
- Multi-provider LLM support via OpenRouter and local Ollama
- Run management with session persistence
- React 19 frontend with Tailwind v4
- End-to-end tested with Playwright
