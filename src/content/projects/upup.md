Contributed to an open-source React drag-and-drop file uploader published on npm as `upup-react-file-uploader`.

## What it does

Upup provides a drop-in React component for file uploads with support for multiple cloud providers: AWS S3, Azure Blob Storage, and any S3-compatible provider via presigned URLs.

## Technical highlights

- Monorepo managed with pnpm workspaces and Turborepo
- Provider-agnostic architecture via presigned URL pattern
- Published on npm with full TypeScript support
